We will have Aldebaran Robotics, maker of the NAO Humanoid Robot, in the NightHacking studio to kick off the event with a presentation and live demo of their Java API. For the remainder of the session we will run an interactive lab using the Choreographe software, which gives you a visual programming interface, and a realtime 3D model of the NAO to test your application.
