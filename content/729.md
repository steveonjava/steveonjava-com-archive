The two talks I gave at Devoxx 2009 are now available on the [Parleys.com](http://devoxx.parleys.com/) website for online viewing.

I would recommend you start with the University Talk, which is the most in-depth tutorial on the JavaFX Language and Platform available today.  This talk also features a guest appearance by Tor Norbye who demonstrated the new NetBeans JavaFX Designer Tool (which is distinct from the Authoring Tool):

![netbeans](/wp-content/uploads/2009/12/netbeans.png)

*Netbeans JavaFX Designer Demo*

[http://devoxx.parleys.com/\#st=5&id=1636](http://devoxx.parleys.com/#st=5&id=1636)

The second is the JavaFX Enterprise Developer talk, which showcased many of the new JFXtras components that we are about to release in the 0.6 JFXtras release (a preview of which is available [today](http://code.google.com/p/jfxtras/downloads/list)).  It also goes into detail on JavaFX unit testing with [FEST-JavaFX](http://fest.easytesting.org/wiki/pmwiki.php), which is a tool any enterprise developer should use regularly:

![devoxx-enterprise](/wp-content/uploads/2009/12/devoxx-enterprise.png)

*Pro JavaFX - Developing Enterprise Applications*

[http://devoxx.parleys.com/\#st=5&id=1593](http://devoxx.parleys.com/#st=5&id=1636)

Both talks are available now for a small fee to register, which is well worth it for all the great content at the conference.  There was a lot of preparation work that went into these talks, so I hope you enjoy them\!
